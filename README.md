# Hellegat

https://hellegat.mariasaha.com

You have reached Hellegat, a spot in New York's East River once feared by mariners. You will wait, like sailors past, for slack water. And when the water calms, it will reward you with an image from the depths, surfacing and then sinking back forever.

The motion of this ebb and flow is like the river breathing. The pause in between each breath, the Slack Water, I decided would be the magical time when the viewer can experience discovering something previously unseen. An image that was there all along, waiting in the stacks of the Public Library. During Slack Water, an image arises, chosen by the river.

More on the [About page](https://hellegat.mariasaha.com/about.html).
